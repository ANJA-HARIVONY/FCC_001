# Rapport — phase 0 et début de phase 1

Date : 19 octobre 2026. Branche : `feat/reecriture-react-node`.

## Ce qui est fait

La phase 0 du plan est fermée. Le comportement Flask utile à la réécriture est écrit dans `docs/parite.md`, à partir du code et d’un relevé MariaDB réel (conteneur `fcc_001_mariadb`), pas d’une reconstitution.

Le package `@fcc/domain` reprend les littéraux, la normalisation, la visibilité (incidencias, clients, salidas, instalaciones, apreciaciones, informes), la pagination et les menus. Les tests `packages/domain/test/domain.test.ts` verrouillent ces règles, en particulier :

- un admin ne voit pas une incidencia d’une autre agencia ni d’une autre ciudad ;
- le même admin peut supprimer une incidencia d’une autre agencia s’il connaît l’id, comme `supprimer_incident` ;
- une note sans ciudad ni agencia n’est lisible que par le superadmin ;
- le filtre d’informe exige l’espace de `"agence_id": <id>` ;
- le menu `Operadores` est absent.

## Relevés

- 18 tables. Noms de colonnes identiques aux modèles, y compris `nom`, `intitule`, `ville`, `date_heure`, `mot_de_passe_hash`.
- Écart de type : `etat.graphiques_data` et `etat.parametres` sont `longtext` en base, `Text` dans SQLAlchemy. Le vivant prime pour Prisma.
- Hash : 33 comptes en `scrypt`, 1 hash vide. Aucun `pbkdf2` actuellement. Le vérificateur Node devra quand même accepter `pbkdf2:sha256:`.
- Filtre informes : `Etat.parametres.contains('"agence_id": <id>')`. L’agencia 10 correspond aussi à un paramètre `100`. Comportement conservé tel quel, testé.
- `.gitignore` ignorait tout `docs/`. Le plan n’était donc pas versionnable. L’ignore est limité à `docs/_build/`. `node_modules/` est ignoré.

## Ce qui n’est pas fait

La phase 1 s’arrête au package domaine. Il manque encore, dans l’ordre du plan : Docker de l’API et du web, Prisma `db pull`, modules NestJS, session, CSRF, vérificateur Werkzeug, audit, en-têtes, et l’application React. Aucune ligne d’écran n’a été écrite, conformément à l’ordre « gel avant React ».

Les 4 fichiers `tests/*.py` restent l’oracle des parcours HTTP. Leurs équivalents Jest ou `node:test` d’API viendront avec chaque module, pas dans ce lot.
