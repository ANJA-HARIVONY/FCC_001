# Rapport — phase 2, coquille React

Date : 19 octobre 2026. Branche : `feat/reecriture-react-node`.

## Ce qui est fait

`apps/web` (Vite, React, Bootstrap) reprend le menu de `_sidebar.html` via `navForRole`.

- Un `usuario` ne voit pas Materiales, Instalaciones ni Administración.
- Un `admin` voit Materiales et Instalaciones, pas Usuarios.
- Un `superadmin` voit Usuarios, Trazabilidad et Base de datos.
- `Operadores` n'apparaît pas.
- Une route interdite affiche 403. Une route inconnue affiche 404. Une erreur de rendu affiche 500.
- Sans session, les pages renvoient vers `/login`.
- Le client HTTP envoie le cookie et `X-CSRFToken`. Une erreur JSON espagnole est affichée telle quelle.
- La pagination 50 / 100 / 200 / 500 est sur la liste Incidencias, encore vide.
- La bannière de session apparaît dans les deux dernières minutes et propose Continuar (ping).
- Ayuda a deux sommaires : `#aide-toc` et `#aide-toc-mobile`. Les sections admin et superadmin suivent le rôle.
- i18next charge les catalogues Babel (`es` par défaut, repli sur le msgid si la traduction est vide). Le sélecteur ES / FR / EN est dans l'en-tête.

Les écrans métier affichent seulement leur titre. Aucun appel de liste n'est branché.
