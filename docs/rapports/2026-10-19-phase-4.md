# Rapport — phase 4, Incidencias

Date : 19 octobre 2026. Branche : `feat/reecriture-react-node`.

## Ce qui est fait

### API (`apps/api/src/incidencias`)

- Liste, détail, création, modification, suppression filtrés par la règle 10.4 (`operateur.id_agencia` + `client.id_ciudad` ; superadmin sans filtre).
- Création : client obligatoirement dans la ciudad de l’utilisateur (sauf superadmin).
- `id_operateur` = créateur immuable ; édition → `id_operateur_modificacion` + `modifie_le`.
- Changement de `status` → ligne `incident_estado_historial` ; `ref_bitrix` normalisé (chiffres 1–10) ; invalidation du cache Bitrix en base si statut/réf change.
- Commentaires ≤ 1000 car. ; notifications au créateur et commentateurs antérieurs ; marquage lu à l’ouverture de la fiche.
- Suppression : créateur ou admin (sans refiltre d’agencia, comme le Flask).
- `GET /api/incidents/clients` : clients éligibles au mouvement.

### Web

- Liste avec filtres (buscar, estado, usuario, ciudad, agencia, fechas, pagination 50/100/200/500), compteurs Corporativo/Particular.
- Nueva / Modificar (recherche client, états littéraux, ref Bitrix).
- Fiche : détails, historial, commentaires, lien client.
- Ayuda `#incidencias` mise à jour.
